# 🎮 What Makes a Steam Game Well-Rated?

> Exploring which game attributes correlate with positive Steam reviews.

---

## Overview

This project investigates what characteristics of a Steam game are associated with positive user reviews. Through exploratory data analysis and predictive modeling, we attempt to answer: **given a game's attributes, can we predict whether it will be well received by players?**

---

## Research Questions

- Do cheaper games tend to be better rated?
- Which genres consistently receive higher scores?
- Does supporting more languages correlate with better reviews?
- Do DLCs and microtransactions negatively impact ratings?
- Are indie studios rated differently from major publishers?
- Does average playtime correlate with review scores?
- Does release timing (month/season) affect reception?
