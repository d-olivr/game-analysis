# CONTRIBUTING

To contribute to this project start with these first steps:

## 1. Installing UV

- On Windows

```bash

```

- On Linux

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## 2. Cloning the repo

```bash
git clone https://github.com/d-olivr/game-analysis.git
cd game-analysis
```

## 3. Syncing the UV

```bash
uv sync
```

### 3.1. Running any script

Utilizing UV you can run any script without activating an environment. Just run

```bash
uv run {script_name}.py
```
